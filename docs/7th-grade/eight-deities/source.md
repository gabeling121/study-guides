The Greek Pantheon contained the Roman Pantheon plus the following eight deities.

| Roman | Greek | Realm | Symbols |
|---|---|---|---|
| Caelus | Uranus | The heavens |  |
| Vesta Prisca/ Tellus | Gaea | The earth |  |
| Saturn | Cronus | Harvest (later, Time) | A sickle |
| Cybele / Magna Mater | Rhea | Earth’s productivity | Lion-drawn chariot |
| Pluto / Dis | Hades | Underworld, wealth | Cerberus, cypress, bident, black-horse chariot |
| Bacchus (Liber) | Dionysus | Wine, revelry, drama | Ivy, grapes, leopards |
| Sol | Helios | Early sun god | sunburst |
| Luna | Selene | Moon, childbirth | Long wings, golden diadem, cow-drawn chariot (w/ crescent horns) |
